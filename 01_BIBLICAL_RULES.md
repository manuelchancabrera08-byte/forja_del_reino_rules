# 01 — Reglas de Fidelidad Bíblica

## Regla principal

La escena debe representar lo que sucede en el relato bíblico, no una versión “más cinematográfica”.

## Antes de crear

Para cada historia, registrar:

- Pasaje principal
- Qué sucede explícitamente
- Quiénes están presentes
- Lugar
- Hora o contexto si se conoce
- Acción principal
- Diálogo explícito, si existe
- Elementos sobrenaturales explícitos
- Elementos no descritos que deben evitarse

## Lo que no debe inventarse

No añadir automáticamente:
- rayos;
- explosiones;
- halos;
- terremotos;
- fuego;
- ángeles visibles;
- alas;
- armas;
- multitudes;
- clima extremo;
- voces celestiales;
- gestos específicos;

salvo que el pasaje lo describa o sea una licencia visual previamente aprobada.

## Ángeles

No asumir que todo ángel tiene alas.

Si el pasaje no describe su apariencia:
- preferir figura humanoide;
- presencia sobria;
- si se usa luz, que sea una licencia visual moderada;
- no usar estética de fantasía.

## Milagros

El milagro debe:
- ser reconocible;
- respetar la secuencia del relato;
- conservar continuidad después de ocurrir;
- no “resetearse” antes del final del clip.

Ejemplo:
si el mar se abre, debe permanecer abierto durante el resto del fragmento si el relato no indica que se cierre en ese momento.

## Diálogo

Si se utiliza diálogo textual de la Biblia:
- puede adaptarse a español latino natural;
- conservar el sentido;
- no agregar ideas doctrinales ajenas al pasaje;
- no convertir la escena en sermón.

## Regla de sobriedad

Cuando el texto no da un detalle, escoger la opción más:
- plausible;
- sencilla;
- históricamente compatible;
- físicamente creíble;
- visualmente discreta.
