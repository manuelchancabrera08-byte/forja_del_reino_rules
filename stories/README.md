# Historias

Cada historia nueva debe crear su propio archivo usando `../10_STORY_TEMPLATE.md`.

Ejemplo:

```text
stories/
  mujer_adultera_juan_8.md
  resurreccion_lazaro_juan_11.md
  horno_de_fuego_daniel_3.md
```

No comenzar a generar imágenes o prompts hasta que el archivo de historia tenga definidos:
- pasaje;
- Video 1;
- Video 2;
- acción principal de cada uno;
- continuidad;
- elementos prohibidos.
