# 07 — Checklist de Calidad

No aprobar una escena hasta revisar todo.

## Biblia

- [ ] ¿El momento existe realmente en el pasaje?
- [ ] ¿La secuencia es correcta?
- [ ] ¿Se inventó algo innecesario?
- [ ] ¿El diálogo conserva el sentido bíblico?
- [ ] ¿No se agregaron efectos sobrenaturales que el texto no exige?

## Formato

- [ ] ¿La historia está dividida en 2 videos de 15 s?
- [ ] ¿Ambos pertenecen a la misma historia?
- [ ] ¿Hay continuidad entre Video 1 y Video 2?
- [ ] ¿Cada clip tiene una acción principal clara?

## Cámara

- [ ] ¿Parece celular real?
- [ ] ¿La distancia tiene sentido?
- [ ] ¿La persona podría estar físicamente en esa posición?
- [ ] ¿Hay microtemblor, no movimiento cinematográfico?
- [ ] ¿No hay crane/dolly/orbit/camera rise?
- [ ] ¿El zoom, si existe, es digital e imperfecto?
- [ ] ¿Si hay zoom, puede empezar abierto, acercar brevemente y terminar menos cerrado cuando convenga?
- [ ] ¿El autofocus puede fallar un instante y recuperar sin parecer efecto de cine?
- [ ] ¿La toma no está siempre demasiado cerca?

## Imagen

- [ ] ¿No está demasiado nítida?
- [ ] ¿Tiene ruido/compresión moderados?
- [ ] ¿El foco puede respirar o fallar ligeramente?
- [ ] ¿No parece película?
- [ ] ¿No parece una imagen IA pulida?
- [ ] ¿La composición es suficientemente casual?

## Física

- [ ] ¿Nadie desaparece?
- [ ] ¿Nadie cambia de frente a espalda instantáneamente?
- [ ] ¿Nadie cambia de tamaño sin razón?
- [ ] ¿No hay teletransportes?
- [ ] ¿Los objetos no se duplican?
- [ ] ¿La gravedad es coherente?
- [ ] ¿Las colisiones son coherentes?
- [ ] ¿La multitud está a distancia segura cuando corresponde?
- [ ] ¿El milagro mantiene su estado una vez ocurrido?

## Audio

- [ ] ¿Los sonidos coinciden con la acción?
- [ ] ¿La distancia sonora es coherente?
- [ ] ¿No hay música si no se pidió?
- [ ] ¿El diálogo suena natural y latino?
- [ ] ¿No hay efectos mágicos genéricos innecesarios?
- [ ] ¿Si la grabación es oculta, se oyen de forma sutil ramas, hojas, tela o respiración contenida?
- [ ] ¿Si habla Jesús, su voz evita sonar genérica, teatral o de locutor?

## Continuidad entre clips

- [ ] ¿Mismo vestuario?
- [ ] ¿Mismos personajes?
- [ ] ¿Misma ubicación?
- [ ] ¿Misma iluminación?
- [ ] ¿Objetos en el estado correcto?
- [ ] ¿Video 2 no resetea Video 1?
